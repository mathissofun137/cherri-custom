# Cherri Safari

A locally runnable Cherri browser with a Safari-inspired appearance.

This project is derived from [x8rr/cherri](https://github.com/x8rr/cherri), licensed under AGPL-3.0. The browser styling and local Wisp server setup were adapted for this copy; the proxy runtime is from the upstream project.

## Run

Install dependencies with `npm install`, then run `npm start`. Open `http://localhost:3001/`.

On the current Windows setup, you can also run `server.ps1` from PowerShell.
